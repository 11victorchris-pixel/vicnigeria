VicBirth Nigeria

Online Birth Recording System — Digital Birth Recording, Made Simpler.

About this demo

  • Built with HTML5, CSS3, vanilla JavaScript & Bootstrap 5
  • Data stored only in browser localStorage
  • Use fictional records — never real personal data
Please note: VicBirth Nigeria is an independent academic demonstration project. It is not an official government registration platform. Records and registration IDs generated here are for demonstration purposes only.
